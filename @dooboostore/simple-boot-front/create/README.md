create-simple-boot-front
===
## simple-boot-front default template creator
Published as `@dooboostore/create-simple-boot-front`. Prompts for a project name (if not given) and a template (`browser-usage, commonjs-typescript-webpack`), then downloads it from `simple-boot-front/default-template` via degit.
```
npm init @dooboostore/simple-boot-front projectname
cd projectname
npm install
npm run dev
```
