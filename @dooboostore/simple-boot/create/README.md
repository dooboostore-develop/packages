create-simple-boot
===
## simple-boot default template creator
Published as `@dooboostore/create-simple-boot`. Prompts for a project name (if not given) and a template (`browser-usage, commonjs-typescript-webpack`), then downloads it from `simple-boot/default-template` via degit.
```
npm init @dooboostore/simple-boot projectname
cd projectname
npm install
npm start
```
