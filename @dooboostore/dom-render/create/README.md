create-dom-render
===
## dom-render default template Creator
```
npm init @dooboostore/dom-render projectname
cd projectname
npm start
```
The CLI prompts for a project name (if omitted) and a template (`browser-usage` or `commonjs-typescript-webpack`), downloads it with `degit`, and runs `npm i`.

## tip
Try clearing the cache with npx clear-npx-cache and then attempt again if the latest changes are not applied.
```shell
npx clear-npx-cache
```
