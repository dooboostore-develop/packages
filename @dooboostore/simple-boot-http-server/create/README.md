create-simple-boot-http-server
===
## simple-boot-http-server default template creator
Published as `@dooboostore/create-simple-boot-http-server`. Prompts for a project name (if not given) and a template (`commonjs-typescript-webpack`), then downloads it from `simple-boot-http-server/default-template` via degit.
```
npm init @dooboostore/simple-boot-http-server projectname
cd projectname
npm install
npm start
```
