create-simple-boot-http-server-ssr
===
## simple-boot-http-server-ssr default template creator
Published as `@dooboostore/create-simple-boot-http-server-ssr`. Prompts for a project name (if not given) and a template (`commonjs-typescript-webpack`), then downloads it from `simple-boot-http-server-ssr/default-template` via degit.
```
npm init @dooboostore/simple-boot-http-server-ssr projectname
cd projectname
npm install
npm start
```
